# 可微分主频分布对齐损失实验

生成器目标为：

`G_loss = WGAN_G_loss + alpha * dominant_frequency_distribution_loss`

每段 128 点波形先计算全局幅度谱，去除 DC bin 后以 `tau=0.05` 的 softmax 得到可微主频估计。真实与生成 Batch 的主频排序后计算 L1 距离，等价于一维 Wasserstein 距离。

该距离除以 Nyquist 频率，使损失归一化后与 `0.1–1.0` 的权重范围匹配。

参数为：`n_fft=128`、`hop_length=32`、`sample_rate=576000`、`tau=0.05`。

运行 0.1 至 1.0 的权重扫描：

```powershell
D:\Python_env\wavegan_torch\python.exe .\wave_improve_dominant_frequency\run_dominant_frequency_loss_sweep.py --device cuda
```

每个权重分别保存 checkpoint、训练日志、逐 epoch JSONL、evaluation 日志、评估指标和评估图片；汇总指标与图片保存在 `log` 和 `images` 根目录。
